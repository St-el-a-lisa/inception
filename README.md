« Le projet nous oblige à créer nos propres Dockerfiles pour comprendre comment fonctionnent les conteneurs, l'installation des services, les réseaux, les volumes et la configuration du système, au lieu d'utiliser des images déjà prêtes. » 🚀


Docker Hub fournit des images déjà configurées.
Avec Inception, on apprend comment construire une image nous-mêmes.
On découvre les notions de Dockerfile, volumes, réseaux, variables d'environnement et persistance des données.
On comprend mieux la différence entre une machine virtuelle et un conteneur.
